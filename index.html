Senaste incident

16 september 2026 · SQL-databas 0016 (SkolM)

Chefen har kommit fram till att deltagarna vanligtvis inte startar i den wave de borde, så vi ska bara startregistrera dem och när de gått i mål placerar vi dem i rätt wave. Jag vet inte hur man gör detta på loppdagen. Vet inte ens om det ska vara guntime eller netto. Hur ser jag vilka som har startat och inte. Så många frågetecken.

Streaken är bruten. Räknaren startar om från den här frågan.

Svaret, utan frågetecken

Använd netto. Startmattan är klockan. Wave är bara en etikett för vilken startgrupp de faktiskt gick ut med — den sätts efter att starttiden finns, oftast i samband med mål. Gun time används bara om ni saknar startmatta, eller om placering uttryckligen ska vara brutto från pistolskottet.

Netto (chip / startmatta)

Mål minus personens startpassering. Rättvis tid även om någon står långt bak eller hoppar wave.

Gun (brutto)

Mål minus vågens pistol. Fel om de inte startade i den våg de var seedade i. Därför ska vågen rättas till den de faktiskt startade i.

Loppdagen i databas 0016

  1. Seedade vågor får stå kvar som plan, men de får inte styra tiden.
  2. Vid start: bara startregistrera (skriv starttid från mattan). Ingen vågflytt ännu.
  3. Vid mål: spara måltid. Räkna netto = mål − start.
  4. Lägg personen i den våg vars gun-tid är den senaste som fortfarande är ≤ starttiden. Sen ankomst till sista vågen stannar i sista vågen.
  5. Gun time, om ni visar den, räknas mot faktisk våg — aldrig mot den seedade.

Start före första pistol = flagga som manuell. Mål utan start = missad startmatta, inte DNS.

SQL · vilka har startat?

Kör mot SkolM-databas 0016. Byt tabellnamn om er schema skiljer sig, logiken är densamma.

Frågor att klistra in 
-- Startade (har startregistrering)
SELECT Bib, Name, StartTime, PlannedWaveId, ActualWaveId
FROM Participants
WHERE StartTime IS NOT NULL
ORDER BY StartTime;

-- Inte startade (DNS om de heller inte har mål)
SELECT Bib, Name, PlannedWaveId
FROM Participants
WHERE StartTime IS NULL
  AND FinishTime IS NULL;

-- På banan / DNF-kandidater
SELECT Bib, Name, StartTime
FROM Participants
WHERE StartTime IS NOT NULL
  AND FinishTime IS NULL;

-- Mål utan start (missad startmatta)
SELECT Bib, Name, FinishTime
FROM Participants
WHERE StartTime IS NULL
  AND FinishTime IS NOT NULL;

-- Efter mål: lägg i rätt wave utifrån faktisk start
UPDATE p
SET ActualWaveId = w.WaveId
FROM Participants AS p
CROSS APPLY (
    SELECT TOP (1) WaveId
    FROM Waves
    WHERE GunTime <= p.StartTime
    ORDER BY GunTime DESC
) AS w
WHERE p.StartTime IS NOT NULL;

-- Tider mot faktisk våg
SELECT
    p.Bib,
    p.Name,
    p.ActualWaveId,
    p.StartTime,
    p.FinishTime,
    DATEDIFF(second, p.StartTime, p.FinishTime) AS NettoSek,
    DATEDIFF(second, w.GunTime, p.FinishTime) AS GunSek
FROM Participants AS p
LEFT JOIN Waves AS w ON w.WaveId = p.ActualWaveId
WHERE p.FinishTime IS NOT NULL;
